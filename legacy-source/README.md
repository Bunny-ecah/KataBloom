# Original implementation reference

These original Java classes, layouts, images and old tests are preserved for FYP reference. They are outside Gradle's source sets and are not part of the v2 app. Do not add them to the manifest or copy them back into the active source directory.

The v2 app uses `KataBloomActivity` for the main flow and the classes under `learning` for content, round state, storage and progress. It replaces the overlapping original engines and placeholder report calculations with one consistent data flow. Original cloud child profiles can be imported explicitly from the parent account menu. The earlier device guest-garden totals migrate once; original data is not deleted.
